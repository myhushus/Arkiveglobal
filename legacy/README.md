# ARKIVE GLOBAL Website

A responsive bilingual static website for ARKIVE GLOBAL.

## Features
- English and Korean language toggle
- Automatic Korean selection when the browser language is Korean
- Language preference saved in the browser
- Responsive desktop and mobile navigation
- No framework or server required

## Files
- `index.html`
- `styles.css`
- `script.js`

## Local preview
Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Before publishing
1. Confirm the final company description in both languages.
2. Replace `contact@arkiveglobal.com` if necessary.
3. Add the registered company name and address if desired.
4. Add Privacy Policy and Terms pages if forms, analytics, or cookies are introduced.
